本版修正了上一版的前端误判：

上一版把 URL 里的 eo_time 直接当成“过期时间”，只要当前时间超过该数值就弹出“预览链接已过期”。
这会导致刚刚点开的新预览链接也可能被立即误判。

本版改为：
- 不再根据 eo_time 在浏览器端自行判断是否过期；
- eo_token / eo_time 仍原样传递给 API；
- 是否有效完全以 EdgeOne 的真实 HTTP 响应为准；
- 401/403、404、5xx 分别给出不同的诊断提示；
- 修复弹窗中 \n\n 被显示成文字的问题。

测试顺序：
1. 打开最新 EdgeOne 预览链接；
2. 先点“接口自检”；
3. 接口正常后点“立即巡检合肥”；
4. 如失败，新的弹窗会显示真实 HTTP 状态，便于精确定位。
