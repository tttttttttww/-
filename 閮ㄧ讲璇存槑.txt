教师考编信息雷达｜腾讯云原生自动巡检部署说明

这版不需要 GitHub Actions。

你已经绑定 GitHub + EdgeOne 的情况下：
1. 解压 ZIP，把全部文件和文件夹覆盖上传到原 GitHub 仓库根目录。
2. 等 EdgeOne 自动重新部署完成。
3. 用 EdgeOne 控制台生成的最新访问链接打开网页；如果网址带 eo_token / eo_time，请保留，不要手工删除。
4. 先点“接口自检”。显示“接口正常”后，再点“立即巡检合肥”。
5. 成功后“最近巡检：尚未运行”会变成实际时间，“官网覆盖状态”会出现真实抓取结果。

自动机制：
- 87 个固定官方入口分 18 批，每天北京时间 05:10—22:10 分批巡检一遍。
- 每天 02:30 做一批历史深度回溯。
- “立即巡检合肥”会依次扫描前 3 批，覆盖 14 个合肥入口。
- 页面搜索/筛选按钮只筛选已经收录的数据，不会触发联网抓取。

如果“接口自检”都失败：不要继续改招聘规则，也不要反复上传。应查看 EdgeOne Makers → Functions / 构建部署日志，因为这说明函数没有成功部署或访问鉴权仍有问题。
