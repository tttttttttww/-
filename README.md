# 教师考编信息雷达｜部署与使用说明

这是面向你的实际备考条件定制的自动巡检版：2027届应届硕士，本科小学教育、硕士现代教育技术，已有高中语文教师资格证，目标优先初中语文。

## 当前覆盖
- 固定官方入口：87 个。
- 安徽：合肥市及主要区县、马鞍山及安徽其他地市、省级教育/人社/人事考试入口。
- 江苏：泰州、徐州、常州、盐城/大丰、南京、淮安，并补充苏州、无锡、南通、扬州、镇江。
- 上海：市教委、市人社事业单位招聘、上海师范大学就业入口，以及16个区的教育/政府招聘入口。

## 这次新增的关键能力
1. 界面不再显示版本号。
2. 新增“上海”和“沪苏近邻”快捷筛选；你的报考画像增加“当前在上海读研”。
3. 上海语文岗单独提醒核验：普通话二级甲等、非沪籍/非上海生源条件、专业口径和教师资格证学段要求。
4. 新增苏州、无锡、南通、扬州、镇江等江苏巡考来源。
5. 修复政府网站把正式公告/PDF嵌在 iframe/embed/object 时可能读不到的问题。
6. 新增“备考提示”：区分教综重合较高、需要补语文学科知识、公共/职测体系不同、试讲面试为主等；这只是备考方向提示，不替代当年考试大纲。
7. 所有判断仍以官方公告、岗位表和资格审查为准。

## 更新旧部署
如果你已经部署过旧版，不需要重新建项目：
1. 把本压缩包解压后的全部文件覆盖上传到 GitHub 仓库根目录。
2. 确保 `.github/workflows/` 两个工作流仍在。
3. GitHub → Actions → 先运行 `Update teacher exam radar`，再运行 `Deep backfill teacher exam radar`。
4. EdgeOne 绑定 main 分支后会自动重新部署；几分钟后刷新网页。

## 使用时最重要的原则
- 平台负责发现、整理、初筛和保存官方入口；是否能报名以岗位表和招考单位资格审查为准。
- “在上海读研”不等同于上海户籍或上海生源，平台不会替你假定这一身份。
- 初中语文岗位如果只限制中文类专业，平台会提示专业可能受限；若公告允许专业不限、研究生专业不限、任一学历阶段满足或允许教师资格证学科与应聘学科相符，则进入重点核实。
- 历史报名人数、竞争比、进面分等只在能找到明确官方口径时写入，不自行估算。
